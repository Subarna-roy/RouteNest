# RouteNest — Intelligent Travel Route & Itinerary Planner

**Tagline:** Your journey, optimized.

A customer-friendly browser interface for demonstrating a Design and Analysis of Algorithms (DAA) mini project.

## Run the frontend
1. Extract the ZIP file.
2. Open the `RouteNest` folder in VS Code.
3. Open `index.html`. For the recommended setup, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**.
4. Alternatively, double-click `index.html` to open it directly in a browser.

No npm, external packages, or build process are required for the frontend.

## Features
- Search tourist places and filter attractions by city
- Browse attractions and ratings
- Find a shortest route between cities using sample distances
- Recommend attractions within a budget
- Plan visits around available time
- Generate possible trip combinations
- Explain the algorithms in plain language

## DAA concepts demonstrated
Searching, sorting, graph representation, Dijkstra's shortest path, 0/1 Knapsack dynamic programming, greedy time planning, and backtracking combinations. The included Python files preserve the console implementation for reference.

## Important limitation
The browser frontend uses sample data embedded in `index.html`. It does not provide live maps, live traffic, booking services, or real-time prices. Route distances and budget suggestions are for academic demonstration only.
