PROJECT OVERVIEW

A simple travel experience, powered by algorithms

Travellers use simple choices. Algorithms work behind the scenes to compare options and help make a plan.

🔎 Find a place

Searching algorithms look through attractions and find a matching place.

⭐ Rank attractions

Sorting algorithms put highly rated attractions first.

🗺️ Shortest route

Dijkstra's algorithm compares city routes and finds the smallest total distance.

💰 Budget planning

Dynamic programming (0/1 Knapsack) selects a combination without exceeding the budget.

⏰ Time planning

A greedy strategy chooses shorter visits first to fit more attractions into your available time.

🗓️ Trip ideas

Backtracking explores possible combinations that meet the budget and place-count limits.

🌐 Explore cities

City routes are represented as a graph, allowing graph traversal algorithms to explore connections.

📊 Algorithm analysis

The project demonstrates how different approaches solve practical problems and how their performance can be analysed.

Academic demo note: this is a browser-based frontend using sample data. It does not use live maps, traffic, bookings, or real-time prices. It is a visual demonstration of the project concept.
